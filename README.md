# 手机通知氛围灯效果设置 - 多语言交互与 DYNAMIC SOUND 原型系统

本项目为三防旗舰机型**通知氛围灯设置页**的高保真纯前端可交互原型，重构并实现了基于**浅色高质感胶囊选择器**、**多语言自适应排版**以及与硬件 **DYNAMIC SOUND 模组**实时联动的完整交互体系。

---

## ✨ 核心特性与定稿规范

### 1. 全 6 种通知灯效
1. **呼吸 (Breathing)**：仿生渐明渐暗呼吸光效，光晕柔和扩散收缩。
2. **脉动 (Pulsing)**：方案 4 能量脉冲节拍柱图标（4 柱均衡律动），双脉冲高频震荡感。
3. **流光 (Streamer)**：360° 标准正圆环闭环光效，高光顺时针流动。
4. **流水 (Water Flow)**：270° 水流弧光追逐，带 90° 纯黑暗区缺口，高度还原参考设计。
5. **彩色律动 (Color Rhythm)**：全光谱色相流动变换，结合模拟音频节拍起伏。
6. **四色律动 (4-Color Rhythm)**：四色交替追逐跳动，充满动感与层次。

### 2. 选色与选中效果全局实时联动
- **选中描边跟随选色**：当前选中的灯效胶囊，其高质感细描边（`border-color`）与外围轻微光晕（`box-shadow`）与下方**颜色选择**（5 快捷预设色 + 全彩拾色轮）实现 100% 实时动态联动。
- **0.25s 平滑过渡**：颜色切换时自然流转，温润优雅，消除突兀跳色。
- **双向边缘羽化遮罩**：横向滑动胶囊容器时，左侧与右侧边缘均具备自适应平滑羽化渐隐遮罩（Fade Mask），无生硬边缘裁切。

### 3. 出海多语言排版适配

## 🛠️ 技术栈与架构
- **HTML5**：语义化排版、纯 SVG 矢量图标绘制。
- **Modern CSS3**：CSS 变量 (`var(--active-halo-color)`)、Flexbox/Grid、Conic-gradient、Keyframes 动效。
- **Vanilla JavaScript**：轻量原生 JS 控制器 (`app.js`)，无外部冗余依赖，秒级加载。

## 🚀 本地运行体验

无需任何构建工具或环境依赖，直接在浏览器中打开 `index.html`，或启动本地静态服务器：

```bash
# 进入工程目录
cd "氛围灯功能"

# 启动本地服务
python3 -m http.server 8080
```

打开浏览器访问 `http://localhost:8080/` 即可体验。
